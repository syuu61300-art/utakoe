# UTAKOE 運営者メモ

※ このファイルは運営者用です。公開フォルダ（public/）には置かないでください。

## 動かし方
1. Node.js 20 以上を用意
2. `.env.example` を `.env` にコピーし、`ANTHROPIC_API_KEY` を入れる（任意で `AUDD_API_TOKEN`）
3. `npm start` → http://localhost:3000

公開する場合は HTTPS 必須です（マイクは HTTPS か localhost でしか使えません）。
Render / Railway / Fly.io などの Node 対応ホスティングにそのまま置けます。環境変数はホスティング側の設定画面で入れてください。

## 仕組み
- **声の文字化**：ブラウザの音声認識（Chrome・Edge・Safari）。19言語から選択、または自動。
- **一語ずつ表示**：認識した単語を1秒置いてから一語ずつ表示（日本語・中国語・タイ語も単語単位に分割）。
- **曲の判定**：8語ごと（最短6秒おき）に、サーバーの照合エンジンへ直近の歌詞を送信。
  - `AUDD_API_TOKEN` があれば、直近9秒の音声でも照合（原曲の音源が流れている場合に強い）。
  - 判定できたら画面で5秒の照合表示 → 曲名・アーティスト・発表年・曲の内容・テーマ・各種リンクを表示。
- **歌詞表示**：曲カードには「あなたが歌った歌詞」をリアルタイム表示。正式な歌詞は著作権の関係で、検索リンク（Google・Genius）から開く形です。
- 照合エンジンとキーはサーバー側だけにあり、利用者の画面・ページのソースにはその存在を示す記述はありません。

## 調整ポイント（public/index.html）
- 表示までの待ち時間：`enqueue()` の `1000`（ミリ秒）
- 曲表示までの待ち：`think()` の `5000`
- 照合の頻度：`maybeIdentify()` の `8`（語数）と `6000`（ミリ秒）
- 表示する確信度の下限：`0.6`
